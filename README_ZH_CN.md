# Astra Launcher

[English](README.md) | [简体中文](README_ZH_CN.md) | [繁體中文](README_ZH_TW.md)

**面向 Android 的非官方 Minecraft: Java Edition 启动器修改版。**

Astra Launcher 由 **AstraDev** 维护，基于 RayLauncher 对 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的修改版本，提供 Android 平台上的自定义启动器体验与界面改进。
