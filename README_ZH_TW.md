# Astra Launcher

[English](README.md) | [简体中文](README_ZH_CN.md) | [繁體中文](README_ZH_TW.md)

**適用於 Android 的非官方 Minecraft: Java Edition 啟動器修改版。**

Astra Launcher 由 **AstraDev** 維護，基於 RayLauncher 對 [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) 的修改版本，提供 Android 平台上的自訂啟動器體驗與介面改進。
